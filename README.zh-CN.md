# Anima Contact Regional LoRA

用于 ComfyUI 的 Anima 空间身份条件、局部 LoRA 路由与结构控制插件。

[English](README.md) · [算法说明](docs/ALGORITHMS.md) · [模型文件](docs/MODELS.md) · [节点参考](docs/NODES.md)

插件为可见归属区域分配独立文本条件和可选 MODEL 适配器，使用共享场景基线维持构图与交互，通过独立的 LLLite 结构条件约束几何关系。使用时不需要训练模型，也不需要修改 ComfyUI 核心文件。

## 功能

- 分离共享场景、全局画风与逐身份条件。
- 每个身份支持多条局部 LoRA 或受支持的线性 LoKr，具有独立开关和倍率；空组使用底模条件。
- 二次元人物检测、SAM2 与 SAM3 实例分割、独立 ISNet/ToonOut 前景分割与遮罩融合。
- 带颜色、名称和缩略图的持久化归属编辑；参考变化后自动清空不适用的笔画。
- 删除、忽略或静音身份节点后同步图例和角色链；未绑定区域保留底模与共享场景。
- 带扩散时间表的 Anima LLLite 控制，以及对生成图进行像素缩放、VAE 重编码和 Tile 精修。
- 通过 ComfyUI 官方本地化机制切换英文、简体中文节点名称、参数和提示。

## 安装

将外层 `Anima-Contact-Regional-LoRA` 目录放入 `ComfyUI/custom_nodes`，使用 ComfyUI 实际运行的 Python 安装 `requirements.txt`，重启并刷新浏览器缓存。安装目录中只保留一份本插件。

Anima 底模、兼容的 Qwen 文本编码器与 VAE 使用 ComfyUI 原生加载节点。不要替换为无关架构的文本编码器或 VAE。SAM2 分割额外依赖官方 [SAM2 软件包](https://github.com/facebookresearch/sam2)；仅使用前景分割或身份图导入时不需要 SAM2。SAM3 使用独立的可选依赖 `requirements_sam3.txt` 与模型目录，详见[模型说明](docs/MODELS.md)。

插件启动时会创建缺失的检测、前景分割、SAM2、模型补丁与控制权重目录，不会在启动时下载所有权重。支持的加载节点在执行且启用“自动下载”时下载缺失预设，验证 SHA256 后原子安装；已有同名文件校验不符时不会覆盖。

## 使用流程

使用真实参考图时：

1. 加载图片，通过“Anima 人物检测”获取人物框。
2. 可通过独立“Anima 前景分割”获取联合前景，或接入其他分割插件的遮罩。
3. 将图片、人物框和可选前景接入“Anima 实例分割”，再用“Anima 归属编辑器”核对人物归属。
4. 建立“Anima 场景条件”，为需要生效的归属 ID 建立“Anima 身份条件”，将身份链接入“Anima 区域路由”。
5. 通过“Anima 布局控制图”提取结构表示，使用“Anima LLLite加载器”加载匹配权重，再应用到区域管线。
6. 使用原生 ComfyUI 节点采样。需要后续精修时，将生成潜空间样本、对应管线、兼容 VAE 和 Tile 权重接入“Anima Tile放大”。

区域标识负责关联遮罩和条件分支；显示名称不必与 LoRA 文件名一致。前景分割只预测主体并集，不判断遮挡肢体属于哪个人物；这些归属需要通过明确种子或涂改修正。

## SAM3 概念分割

“Anima SAM3 语义分割”接收单张 RGB 参考图。自动模式依次探测 `person`、`girl`、`boy`，再对重复实例去重；自定义模式每行输入一个简短英语概念短语，每条短语都可匹配多个实例。自动模式是固定人物概念探测，不是自动图像描述模型。

节点保留 SAM3 的实例轮廓，重叠像素按置信度竞争，不重新运行 SAM2，也不按左右距离切分肢体。身份按掩码重心排序；连接身份条件前应检查颜色图例。预期实例数大于零时核对结果，不截断或虚构人物。

使用 ComfyUI 实际运行的 Python 安装 `requirements_sam3.txt`。“自动下载”从公开的 [bodhicitta/sam3](https://huggingface.co/bodhicitta/sam3) 仓库获取权重和配置，无需登录或令牌；文件校验值与 Meta 上游导出一致。节点通过 Transformers 支持 CPU 与 CUDA，推理后释放模型。固定修订、目录与磁盘空间见[模型说明](docs/MODELS.md)。遮挡、小人物等情况仍需检查分割结果。

## 示例

`example_workflows` 包含七套工作流，所有身份初始适配器组均为空，说明默认为中文。

| 工作流 | 分割路线 |
|---|---|
| 双人 SAM3 | SAM3 概念实例分割 |
| 双人 SAM2 | 二次元人物检测与 SAM2 |
| 双人前景分割 | 前景模型、明确身份种子与测地归属；不加载 SAM |
| 三人、五人、七人 | 每种人数各一套 SAM3 工作流 |
| 双人 Tile 二采放大 | SAM3 后接生成图 Tile 精修 |

将真实人物参考图拖入原生“加载图像”节点。每套仅连接对应的一条分割路线。前景工作流需要先局部执行身份种子节点载入画布，标注每个人物及交叠肢体，再队列整个工作流；联合前景本身不区分人物。潜空间尺寸随涂改后的归属布局输出。不携带个人文件名、预选 LoRA 或图片缓存。

`examples/reference_guides` 中的参考图、身份图与轮廓 PNG 均由 Python 生成。可使用以下命令重新生成工作流和素材：

```bash
python tools/build_examples.py
```

这些素材用于演示结构输入的几何含义，不是艺术素材、分割精度评测或生成图质量对比。

## 算法与模型

人物框由 DeepGHS 二次元人物检测器产生，SAM2 根据框或身份种子预测实例候选。前景概率图可以在边缘感知归属分配前补充漏选像素。孤岛、封闭孔洞及互斥标签边界先清理，再应用受保护的人工笔画。

路由引擎相对共享条件基线计算区域文本残差，相对对应未适配分支计算适配器残差。原生带权模块保持对象身份；临时钩子限制在模型调用范围内，调用结束后恢复。可选自注意力隔离在指定层抑制不同归属区域的通信，同时保留背景连接；该功能为实验性功能，默认关闭。

结构控制预设包括 Anima 轮廓 LLLite、实验区域色块 LLLite 与 TileRepair。Tile 精修使用首采生成 RGB 作为条件，不使用原参考图或身份色块图。完整模型目录、固定下载来源、校验值与上游许可见 [MODELS.md](docs/MODELS.md)。

## 限制与诊断

区域路由和控制接入面向原生28层 Anima Base 架构，不会使不兼容架构或任意全局适配器目标自动获得空间局部性。投影匹配严格执行；文件缺失或零匹配时直接报错，不静默退回文字身份。

人物越多，每个人分到的可见像素越少。遮罩缺失、归属门控降采样与共享注意力都可能在名义适配器强度不变时削弱外观。结构控制不能取代语义身份条件；替换 VAE 不能解决去噪阶段已经发生的身份混合。相关分析、依据和隔离机制的局限见 [ALGORITHMS.md](docs/ALGORITHMS.md)。

采样后通过“Anima 区域诊断”查看实际门控与适配器活动。CPU 数学测试、浏览器检查和真实前景模型接口检查的范围见 [VALIDATION.md](docs/VALIDATION.md)，这些结果不代表在所有 ComfyUI 发行版和 GPU 上完成验证。
